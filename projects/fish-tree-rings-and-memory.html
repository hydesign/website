Fish, Tree Rings and Memory Technology

2019 Installation Tree Ring, Interactive system, fish

Fish, Tree Rings and Memory Technology is an installation for creating memory technology for goldfish. This project wants to create a spectrum through the interaction of golden fish, technology and annual rings, and give the audience a different imagination from human experience. The movement of the goldfish's position is signalled in the computer's recursive operation to the drill on the right, which will re-carve the tree's rings.
